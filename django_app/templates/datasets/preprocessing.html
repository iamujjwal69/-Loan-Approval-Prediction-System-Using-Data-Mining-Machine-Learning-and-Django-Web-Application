Categorical Encoding Architecture

Categorical string variables are transformed via Scikit-Learn OneHotEncoder to eliminate arbitrary ordinality assumptions.

  • Gender (Male, Female) One-Hot Encoded
  • Married (Yes, No) One-Hot Encoded
  • Dependents (0, 1, 2, 3+) One-Hot Encoded
  • Education (Graduate, Not Graduate) One-Hot Encoded
  • Self_Employed (Yes, No) One-Hot Encoded
  • Property_Area (Urban, Semiurban, Rural) One-Hot Encoded

Numerical Feature Standardization

Continuous variables are standardized using StandardScaler: $z = \frac{x - \mu}{\sigma}$. This aligns features with different units (e.g. Income in thousands vs Term in months).

  • ApplicantIncome Z-Score Standardized ($\mu=0, \sigma=1$)
  • CoapplicantIncome Z-Score Standardized ($\mu=0, \sigma=1$)
  • LoanAmount Z-Score Standardized ($\mu=0, \sigma=1$)
  • Loan_Amount_Term Z-Score Standardized ($\mu=0, \sigma=1$)
  • Credit_History Binary Guidelines Indicator (1.0 / 0.0)
